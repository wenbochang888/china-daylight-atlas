# 中国昼夜地图

选择上一年或当前年中的一天，观察中国各地的白天与黑夜。两个完整年份均可选择，包括当年未来日期。支持固定全国总览、省级详情、代表点日出日落、当年二十四节气一键播放和两天同步对比。电脑采用主地图与右侧观测栏，手机通过“地区详情”“日期与节气”面板操作。

Vue 3 + TypeScript + Vite + MapLibre GL JS。地图、名称索引和依赖随静态站点提供，天文计算在浏览器完成；无需数据库、自建后端、账号或 API Key。

## 启动

需要 Node.js 22 或更新的兼容版本。已在 Node.js 22.23.3 验证。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。当前交付目录已安装依赖，可直接执行 `npm run dev`。如果端口被占用，Vite 会显示实际使用的端口。

同一局域网的手机可通过终端显示的 Network 地址访问；电脑和手机需要处于同一网络，电脑允许该端口连接。

## 构建为静态网页

```sh
npm run build
npm run preview
```

默认预览地址为 `http://localhost:4173`。将完整 `dist/` 目录部署到任意静态 HTTP 服务即可，保留 `maps/` 与 `assets/`。工程使用相对资源路径，支持部署到子目录。通过 HTTP／HTTPS 访问，不要直接双击 `index.html`。

运行时请求均为本站静态文件，不调用第三方行政区、瓦片、字体或天文业务接口。用户原有的视频和图片仅用于设计参考，不进入运行时下载。

## 使用

- 点击日期文字、日历图标或整块日期框，打开中文日历；可选择北京时间上一年1月1日至当前年12月31日，范围随北京时间年份滚动。初始日期和日历今天标记使用实际今天。
- 地图顶部显示北京时间与播放／暂停，共享时间轴固定在屏幕底部并与地图区域等宽，滚动时仍可操作。支持点击、拖动及方向键／Home／End，范围 00:00—24:00，精确到分钟。手动操作立即暂停并更新主图、附图及详情，松手保持暂停，不跨日。
- 点击节气，从该日 00:00 自动播放。普通换日保留当前时分并暂停。
- 二十四节气按春夏秋冬四组六项排列，全部显示北京时间当前年份的完整年月日，包含尚未到来的节气；选择上一年日期不改变节气年份。春分／秋分标注“昼夜近等长”，夏至标注“长昼节点”，冬至标注“短昼节点”。
- 全国完全白天或黑夜时每秒推进90分钟，全国存在昼夜交界时每秒推进8分钟。页面固定省级显示，倍率始终为1；阶段判定仍包含官方全国多部件及全部海岛几何，不依据主图展示范围或选区。
- 到 24:00 停止，所选日期保留；再次播放从当天 00:00 开始。进入后台暂停，返回后需手动播放。
- 昼夜播放时同时播放固定钢琴音乐，音乐保持正常速度、结束后循环；初次打开页面不会播放或预先下载 MP3。音乐位置按从00:00正常播放至地图当前时刻的累计秒数定位，包含90／8分钟每秒的快慢段，超过曲长取余。拖动立即暂停并跳到目标时刻对应的音乐位置，继续播放从此处开始；普通换日与单双图切换按新日期／合并速度段重新定位，节气及日终重播从零点开始。暂停及后台不推进，双图共用一份音乐。
- 音乐加载失败或声音播放被浏览器拦截时，昼夜演示仍继续；页面显示提示，地图播放期间可点击“重试音乐”。无需选择曲目或安装额外播放器。
- 全国地图固定，不能手动缩放、拖动或旋转。所有尺寸显示34个省级名称，点击行政面或名称仅高亮并显示代表点详情；手机直接打开详情面板，关闭后焦点回到详情入口。地区详情中的“全国”清除选区与高亮，地图视角不变。市级、县级数据继续保留，此轮页面不提供下钻。
- 中国轮廓“背部”上方的时间卡片按“日期、北京时间、时分”排列，与顶部原时钟、时间轴和播放共用分钟，显示00:00—24:00。地图不再显示小房子按钮、左上角省级标记或右下角数据取得文字，来源记录保留在文档。地图采用青绿陆地、浅蓝海面与深蓝夜色，金色显示时刻与选区。主图到海南主体，南海诸岛和相关境界线在右下角附图完整展示。窄图为附图留出独立区域，避免遮住海南、港澳台及东南沿海。
- “两天对比”共享时刻、选中地区与固定全国取景；每张图各有大时间和南海附图。任一天有昼夜交界就慢放。节气可应用于日期 1 或日期 2；地图容器宽度达到 920px 时左右排列，否则上下排列。
- 关闭地区详情保留选区与高亮，可通过详情入口重开；日期固定在桌面观测栏顶部，详情与观测历独立滚动。
- 地区详情仅代表明确标注的位置，同一行政区内可能同时存在白天和黑夜。

## 数据与计算口径

行政区采用[天地图官方公开行政区网页](https://cloudcenter.tianditu.gov.cn/administrativeDivision)的固定快照，取得于 2026-10-02；源页面标示“2025 年 9 月局部更新”。日期选择改变天文时刻，行政区不随所选日期回溯，也不表示实时行政调整。

覆盖 34 个省级区域、333 个市级节点、2883 个县级／对应层级节点。官方目录另有 3 个辅助区域，保留几何并单独分类。原始数据包括香港官方目录的18区与台湾省的20个县市对应层级，澳门目录没有下级节点。当前页面可选择34个省级地区，完整原始目录及387个省市候选节点仍保留。保留全部原始多部件几何与 8 个境界线要素，不自行手绘边界或简化海岛。

南海附图、钓鱼岛及其附属岛屿注记的来源和绘图锚点见[来源记录](docs/data/provenance.md)，逐省覆盖见[覆盖表](docs/data/coverage.md)。源数据的坐标基准未在公开响应中显式声明，保留原始经纬度，不施加 GCJ-02 偏移。

Astronomy Engine 2.1.19 计算太阳向量，地图遮罩和详情使用同一模型：太阳中心几何高度 ≥ −0.8333° 为白天，低于 −0.8333° 为黑夜。边缘只有抗锯齿，不显示第三种状态。采用常规海平面阈值，不模拟天气、山体、建筑遮挡或观测点海拔。

二十四节气通过太阳视黄经每隔 15° 求根，日期转换为北京时间；与[香港天文台节气说明](https://www.hko.gov.hk/sc/gts/time/24solarterms.htm)及[2026 年中气时刻表](https://www.hko.gov.hk/tc/gts/astron2026/files/2026SolarTerms24.pdf)交叉验证。全国播放区间按日预计算并缓存最近 8 天，播放帧按实际经过时间分段积分，不扫描全国坐标。
