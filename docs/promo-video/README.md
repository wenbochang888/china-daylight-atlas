# 中国昼夜地图宣传片

本片按用户确认的八段方案制作：16:9、1920×1080、约60秒，当前应用真实界面、中文女声旁白、中文字幕、仓库现有钢琴曲。

| 时间 | 分镜 |
| --- | --- |
| 0—6秒 | 北京时间18:00的全国昼夜分布，东西部明暗差异 |
| 6—11秒 | 产品名称与完整界面 |
| 11—21秒 | 清晨至傍晚的昼夜流转，注明演示加速 |
| 21—28秒 | 拖动时间轴并停在明确时刻 |
| 28—35秒 | 展示节气列表，点击夏至，从当天零点播放 |
| 35—47秒 | 2026年夏至与冬至07:00并列，先停留再同步推进 |
| 47—54秒 | 点击湖南省，展示代表点日出、日落及昼长 |
| 54—60秒 | 回到全国地图，产品名、宣传语及体验网址 |

地图、日期、遮罩和代表点详情来自当前仓库运行界面。加速展示使用应用的实际分钟状态与太阳模型，未另画昼夜分界。鼠标提示、字幕、片头标题和片尾卡片属于视频包装，未写入产品代码。

旁白使用本机普通话女声 Tingting。配乐为 `src/mp3/钢琴曲.mp3`，旁白期间自动降低配乐音量，首尾淡入淡出。

发布标题：**同样是早晨七点，夏至和冬至的中国有什么不同？**

封面主标题：**同一时刻，不同昼夜**

发布简介：

> 同一个北京时间，中国不同地方的昼夜可能大不相同。
> 在中国昼夜地图中，拖动时间轴观察一天的变化，选择二十四节气，或把夏至与冬至并排比较，还能查看省级代表点的日出、日落与昼长。
>
> 在线体验：https://www.gdufe888.top/sun/
> 项目仓库：https://github.com/wenbochang888/china-daylight-atlas

详细旁白和时间表见 `storyboard.json`，可单独使用的字幕见 `中国昼夜地图.srt`。

重建：在根目录启动本机开发服务 `npm run dev -- --host 127.0.0.1 --port 5178 --strictPort`，再执行 `node scripts/create-promo-video.mjs`。需要现有 Playwright Chromium、本机 `say`、`ffmpeg` 和 `ffprobe`。原始帧与配音保存在系统临时目录，成片及封面保存在本目录。
