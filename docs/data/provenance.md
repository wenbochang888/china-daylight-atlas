# 数据来源与处理记录

记录日期：2026-10-02。当前采用版本 `tianditu-public-2026-10-02`。

## 官方行政区快照

来源为国家地理信息公共服务平台·[天地图行政区网页](https://cloudcenter.tianditu.gov.cn/administrativeDivision)。源页面标示数据“2025 年 9 月局部更新”；取得日期为 2026-10-02。这是固定快照，取得日不等于行政区生效日，应用不恢复历史行政区。

原始文件保存于 `data/source/official/`：目录 `menu.json`、全国 `provinces.json`、362 份下级地图响应，以及描述取得日期的 `snapshot.json`。公开网页自身使用的响应地址如下，无账号、token 或 API Key：

- [行政区目录](https://cloudcenter.tianditu.gov.cn/api/portal/region/menu)
- [全国地图响应](https://cloudcenter.tianditu.gov.cn/api/portal/region/map?gb=156000000&level=2)
- 下级地图按官方节点 `gb` 和层级 `level` 取得，例如省级请求 `level=1`、市级请求 `level=0`。

响应按官方公开客户端的格式解码：gzip 解压后，每四字节按大端有符号整数读取，右移两位并取低八位，拼成 UTF-8 JSON。保存解码后的 GeoJSON，不改变原始坐标、名称或境界线属性。

这些是官方公开网页资源；公开响应未附单独开源许可证，本项目不为地理数据另行授予开源许可，不将第三方仓库许可或来源页面审图号当成本网页的授权／审图号。来源标识随站点保留。

## 几何与显示处理

`scripts/prepare-map-data.mjs` 派生运行时名称索引、标签、全国省界、按省市县分片、独立境界线与清单。全部 Polygon／MultiPolygon 坐标逐值保留，不做边界简化、偏移或并集。境界线的 8 个 MultiLineString 要素保留原始属性与坐标；其线型按官方公开客户端区分，其中 `156970000` 为白色虚线、`156980000` 为蓝色虚线。

官方响应未显式声明大地基准，因此不宣称已证实 CGCS2000／WGS84，也不施加 GCJ-02 偏移。保留原始经纬度，以 MapLibre 的 Mercator 投影显示。渲染器按视野生成显示瓦片，分片本身保留所有原始点。

地名绘图位置 `labelCenter` 保留官方标注点。23 个官方标注点落在本区域面外，其天文详情 `center` 改用原始边界内计算代表点，并注明“根据官方边界计算的内部代表点”；其余注明“官方地图标注点”。不将它们冒称为政府驻地，也不以单点状态代表全域状态。

原始文件和派生文件分开保存，`public/maps/manifest.json` 记录来源、日期及 364 个原始目录／几何响应的 SHA-256。`scripts/check-map-data.mjs` 检查哈希、完整目录、父子关系、34 省、特殊层级、有限闭合坐标、海南南部／台湾东部范围，以及每份派生几何与原始几何逐值一致性。

## 更新方法

当前原始快照保留不覆盖。需要更新时，先重新核验官方页面说明，在一个新的空目录取得快照：

```sh
python3 scripts/fetch-official-data.py --output data/source/official-new --source-update '填入已核验的源页面更新说明'
```

脚本拒绝已有文件的目录，避免新旧响应混合。新快照通过来源、层级及成图对照后，归档旧 `official/`，将确认的新完整目录设为 `official/`，同步本文件的版本说明，再执行：

```sh
npm run data:prepare
npm run data:check
npm run build
```

更新后重新检查港澳台、南海诸岛、钓鱼岛、附属岛屿、境界线和特殊行政层级截图。`data/source/` 中研究阶段的第三方候选文件不进入运行时构建；当前仅使用 `official/` 和明确列出的海岛注记来源。
