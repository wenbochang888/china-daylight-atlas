## 四、阶段 1：日期与天文基础

### [x] 任务 05：固定依赖与静态工程配置

计划创建 Vue 3 + TypeScript + Vite 工程，锁定 MapLibre 与天文库版本，定义 npm 脚本：dev、typecheck、test:unit、test:e2e、data:check、build、preview。不引入后端服务。

验收：安装后启动空页面，typecheck 与 build 成功；所有运行时依赖可由静态站点提供。

### [x] 任务 06：实现并验证北京时间规则

涉及 beijing-time.ts 与对应单元测试。用注入的当前时刻测试 2026-10-02、2028-02-29、跨北京时间零点、设备不同时区及 24:00。测试期望见 spec 第 10 节，不用真实系统时钟制造偶发结果。

### [x] 任务 07：统一太阳计算语义

涉及 solar.ts 与独立参考数据。锁定几何高度单位、折射处理、经纬度顺序、海拔模型与事件日期所属。日出日落结果必须属于所选北京时间日，不能因 UTC 日期不同而取错一天。

验收：多个东西南北代表点与外部天文参考交叉验证，记录来源、坐标、日期、模型和差值；无事件时返回明确空值。

### [x] 任务 08：实现昼夜遮罩计算

实际实现为 solar-layer.ts 逐片元地理高度着色，与 solar.ts 共享太阳向量，避免多边形采样随缩放漂移。已检查阈值两侧、季节差异、全国白天／夜间和附图状态。

阶段出口：时间、地点状态与遮罩使用同一模型；无坐标／单位歧义。

## 六、阶段 3：时间轴、播放与两天对比

### [x] 任务 13：日期与分钟时间轴

涉及 DateControls.vue、TimelineControls.vue、useExplorer.ts。拖动只改变时分；日期选择单独控制，支持 ±30／60 分钟和键盘操作。

验收：在当日 00:00、12:00、24:00 检查跳转、显示和 UTC 转换；改变日期保留时分并暂停。

### [x] 任务 14：播放状态机

涉及 usePlayback.ts。使用单一时间推进来源；依据经过的时间推进，不能依赖每帧固定加值。加入到末尾停止、同日循环、后台暂停和组件销毁清理。

验收：暂停后时刻不再变化；更改速度不创建多个定时器；拖动暂停；循环不切换日期。

### [x] 任务 15：双日期同步

涉及 synchronize.ts 与 App.vue。共享时分，日期独立；共享数据缓存，视角同步防重入。手机上下排列。

验收：同一天两图完全一致；不同天太阳边界不同；一侧缩放两侧到达同一视角且没有持续触发事件；关闭对比后资源释放。
