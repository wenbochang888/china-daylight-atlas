## 1. 产品目标与已确认范围

在中国行政区地图上，选择最近一年内的一天，以当天时间轴观察白天、晨昏与夜间的变化。支持最多两天同步对比。电脑优先，适配 iPhone Safari 与 Android Chrome。

| 项目 | 已确认要求 |
| --- | --- |
| 部署 | 静态网页，无自建后端、数据库、业务 API |
| 联网 | 允许联网加载资源；不要求注册账号或申请 API Key |
| 地图 | 简洁行政区地图；缩放依次显示省、市、县／区，最细到县级 |
| 地图依据 | 以中国政府标准地图及相关官方行政区资料为准；版图正确是首要验收条件 |
| 覆盖 | 全国完整呈现，包含香港、澳门、台湾、南海诸岛等；特殊地区按官方实际对应层级表达 |
| 日期 | 北京时间当天向前一个日历年，起止日期均可选 |
| 时间轴 | 改变时刻，不改变日期；完整当天，分钟精度，前后 30／60 分钟按钮 |
| 昼夜 | 白天、晨昏过渡、夜间；标准天文模型，不模拟云层、建筑和山体遮挡 |
| 地区状态 | 遮罩穿过真实地理范围；详情使用明确标注的代表位置，不能代表整个行政区 |
| 播放 | 播放、暂停、速度选择、可选当天循环；拖动时暂停 |
| 对比 | 单图／双图切换；最多两天，同步时刻与地图视角 |

2026-10-02 打开网页时，可选日期为 2025-10-02 至 2026-10-02。范围不能硬编码为这两个日期，也不能用固定 365 天代替一个日历年。

## 2. 方案比较与推荐

| 路线 | 适用性 | 结论 |
| --- | --- | --- |
| Vue + 本地行政区矢量数据 + 浏览器天文计算 | 无账号、无 Key，数据版本可追踪，不受第三方运行时接口变化影响 | 推荐；先完成数据核验 |
| Vue + 在线商业／天地图 SDK | 底图维护省心，但常涉及 Key、账号、配额或服务约束 | 不符合用户目前约束 |
| 官方静态图片 + 遮罩 | 适合静态展示；缺少区县可查询边界，放大细节有限 | 不作为核心方案 |

推荐技术组合：Vue 3、TypeScript、Vite、MapLibre GL JS、独立天文计算模块。MapLibre 只作为地图渲染器，使用我们核验后的数据和样式，不加载其演示世界底图。所有必要资源随静态站点提供。

地图数据保存为分层、分片的静态文件。浏览器加载的是同域资源文件，不是查询数据库的业务接口。通过静态 HTTP 服务访问；不承诺直接双击 HTML 即可加载所有模块。

## 3. 地图真实性与数据验收

### 3.1 原则

1. 国界、行政区界、重要岛屿、名称、层级和附图表达以中国政府标准为基准。
2. 台湾省作为省级行政单位；香港、澳门作为特别行政区；不能套用第三方全球底图的默认国家分类。
3. 按官方图样核验南海诸岛、钓鱼岛及其附属岛屿、相关境界线与注记。不得凭印象手绘补丁，不自行增删线段。
4. 核验国界与内部行政区面是两项任务。内部区县面的并集不能自动替代国界和岛屿图层。
5. 最细层级须覆盖县、区、县级市、旗、自治县等对应单位；不存在县级下属单位的地区不伪造下一级。
6. 不把开发区、统计区、地图绘制辅助面自动当作正式行政区。名称和数量须与选定版本的官方清单对应。
7. 数据集有来源不等于成图已核验；开源仓库的许可证也不能自动替代原始地理数据的使用条件。

### 3.2 获取与保存

优先寻找可直接获取的官方发布文件。公开转载或转换版本只可作为候选，能否最终使用需确认用户接受范围，并核验官方出处、原始日期、处理记录与使用条件。

每个采用的数据文件保存：原始来源、下载地址、数据日期、下载日期、坐标系、适用层级、处理记录、SHA-256、可核实的使用条件。保留原始文件，不覆盖；处理后另存运行时文件。

行政区地图使用一个固定且注明日期的版本。日期控件仅改变昼夜计算，不实现历史行政区恢复。地图是否必须反映当前最新行政区调整，在数据版本评审时明确，不冒称旧数据是实时地图。

正式编码前提交一份数据核验表，包含每个省级区域的市县数量、上下级关系、缺失项、特殊层级说明和重要岛屿核验结果。国家清单和特别行政区／台湾省资料分开核对，不能用内地统计总数作为全国唯一验收数。

### 3.3 已知研究结论

详见同目录的 `map-data-research.md`。采用官方公开响应的固定快照，3253目录节点均有原始几何，其中3个地图辅助区域单独标记。自动覆盖核验通过，成图视觉检查记录见验证文档。

## 4. 日期与时间规则（细节提案，供审阅）

- 统一 `Asia/Shanghai`，计算时间转换为 UTC 绝对时刻；不能依赖访问者设备所在时区解释日期。
- 当天减一个日历年作为下限。闰日回推遇到不存在的 2 月 29 日时，取前一年 2 月最后一天。
- 页面打开及从后台恢复时重新检查北京时间日期；跨北京时间零点后更新可选范围。已选日期越界时暂停播放并调整到最近有效日期，显示提示。
- 初次打开：单图、今天、当前北京时间（分钟精度）、全国视图、暂停状态。
- 时间轴为 00:00—24:00，内部范围 0—1440 分钟。24:00 表示所选日期的结束边界，等同次日 00:00 的绝对时刻；日期框仍显示所选日，不自动翻页。
- 选择今天时也可观察今天尚未到来的时刻，属于天文预测；24:00 仅作为日终端点，不开放选择未来日期。
- 调整日期保留时分并暂停播放。前后跳转在 0 和 1440 处截断，不跨日。
- 播放速度拟定为每秒推进 5、15、30、60 分钟，默认 15 分钟／秒。速度选项明确写出单位。
- 播放到 24:00 停止；开启循环时回到同一选定日期的 00:00。后台隐藏时暂停，恢复后保持暂停。

## 5. 昼夜计算与视觉（细节提案，供审阅）

拟采用民用晨昏定义，使效果接近参考视频 2。以太阳中心的几何高度 h 分类：

| 显示类别 | 判定 | 说明 |
| --- | --- | --- |
| 白天 | h ≥ −0.8333° | 常规海平面日出日落阈值，包含标准折射和太阳半径近似 |
| 晨昏 | −6° ≤ h < −0.8333° | 根据太阳高度上升／下降区分黎明与黄昏 |
| 夜间 | h < −6° | 民用晨昏之外，不能描述为天文学意义上的完全黑暗 |

图例明确标注“晨昏按民用晨昏计算”。常规标准与实际观测存在天气和地形差异，本产品不显示观测级精度承诺。

天文库候选为 Astronomy Engine；在执行计划定稿时锁定版本与具体接口。地图遮罩和地点详情必须调用同一太阳模型，并显式区分几何高度与经过折射修正的视高度，避免重复折射。不能把一个库的视高度直接套入另一个算法的几何阈值。

遮罩在地理坐标上生成，并经过地图投影显示，不能做屏幕上固定角度的直线动画。建议以太阳位置生成两个高度阈值的地理等值边界，通过嵌套遮罩形成三种颜色。文字和行政区边线置于遮罩上方，夜间依然可读。

细分地图层级时昼夜边界应保持相同地理位置。地图缩放不改变太阳计算结果。分界采样随缩放细化，避免县级视图中锯齿和明显位置误差。

## 6. 地图交互与页面布局

电脑页面：顶部为标题、日期、单图／对比切换；中央为主地图；侧边为可折叠的地区搜索与详情；底部为固定的时间轴、当前北京时间、播放与跳转控件。全国视图完整显示必要地图内容，控件不得遮住重要岛屿。

全国尺度主要显示省级名称和边界；放大后增加市级，再增加县级。平移到邻近地区会加载对应边界，无需反复点击层级按钮。提供地区搜索、点击选择、返回全国和缩放按钮；同名区县搜索结果显示完整归属。

行政区详情拟显示：全名、上下级路径、代表位置名称与经纬度、当前状态、日出、日落、昼长、晨光开始、暮光结束。代表位置优先采用有来源的行政驻地；缺失时只可使用明确标注的地理代表点，不能冒称政府驻地。

地图主要表达真实连续的昼夜范围。列表若按状态筛选，必须明确为“代表位置状态”，不能标成“全省白天”。第一版不计算全省／全市昼夜面积比例。

南海诸岛建议采用独立附图加“查看全境”入口。附图是有真实经纬度的独立视图，使用同一天和时刻重新计算／投影遮罩；不能将主图屏幕遮罩直接盖到搬移后的附图上。全国与海南省级展示需核对对应附图名称、范围和注记。

## 7. 双日期对比

- 最多两天，两个日期都受最近一年范围限制；允许选择同一天用于核对。
- 两个日期共用一个时分和播放控制；绝对 UTC 时刻分别由各自日期计算。
- 电脑左右分栏，手机上下排列；每张地图显示日期。
- 同步中心、缩放和选中地区。同步使用来源标记防止两张地图相互触发无限事件。
- 同日期时两个遮罩应完全一致。切回单图保留第一张图日期与视角。
- 首次开启对比，第二日期建议为第一日期前一天；超出下限则取下限。用户可自由改为范围内任何一天。

## 8. 手机与性能

- 最窄按 360 CSS 像素设计；采用动态视口高度与安全区留白，考虑 iPhone 底部横条。
- 支持双指缩放、单指平移、拖动时间轴；时间轴拖动不能同时触发地图平移。
- 控件触控区域至少 44×44 CSS 像素；地区信息用底部面板，关闭后还原地图可视空间。
- 地图按视野和层级加载；禁止首次打开就解析全部高精度县界。两张地图共享静态数据缓存。
- 时间变化只更新太阳遮罩和可见详情，不重建行政区、不重新下载地图数据。
- 中文字形和依赖使用本地资源；不依赖需要 Key 的字体或瓦片服务。
- 无 WebGL 或渲染失败时显示明确状态与恢复入口，不展示空白地图或伪造结果。
- 性能目标需实测：桌面和普通手机单图拖动目标 ≥30 fps，双图手机目标 ≥24 fps；连续拖动与播放 10 分钟无持续内存增长。记录测试设备和环境，未测试设备不得声称已验证。

## 9. 模块与数据流

| 模块 | 职责 |
| --- | --- |
| 页面状态 | 两个日期、共享时分、播放状态、选中地区 |
| 日期工具 | 北京时间解析、滚动一年范围、闰日、24:00 |
| 天文计算 | 太阳位置、三态判定、地点日出日落 |
| 昼夜几何 | 高度阈值等值线、投影前的遮罩几何 |
| 地图数据仓库 | 静态索引与分片加载、缓存、重试、数据版本 |
| 地图视图 | 分级显示、选择、标注、遮罩与附图 |
| 对比同步 | 两张地图视角与选择的单向传播 |
| 控制组件 | 日期输入、时间轴、播放、搜索、详情 |

数据流为：日期与时分 → UTC 时刻 → 太阳模型 → 遮罩与地点结果 → 地图和详情。缩放与平移只影响视野和数据加载。基础数据错误应独立于天文模块报告。

## 10. 故障与验收

- 地图分片加载失败：保留已有层级，显示当前地区加载失败与重试入口，不能标注“没有下级”。
- 快速搜索／切换地区：丢弃过期请求结果，避免上一次结果覆盖当前视图。
- 天文事件不存在：显示“当日无该事件”，不能显示无效日期、0 点或上一日结果。
- 对比任一视图加载失败：保留另一个视图，并在失败侧明确提示。
- 所有必需资源应能由同一个静态站点提供。首次访问需要网络；不另行承诺完整离线 PWA 能力。

核心验收用例：

| 场景 | 预期 |
| --- | --- |
| 固定当前日为 2026-10-02 | 日期范围精确为 2025-10-02—2026-10-02 |
| 固定当前日为 2028-02-29 | 下限为 2027-02-28 |
| 设备时区改为纽约 | 日期范围和相同时刻的地图保持北京时间语义 |
| 从 00:00 后退／24:00 前进 | 截断，不更换日期 |
| 日期选今天，时间选今晚 | 允许查看标准天文预测 |
| 同一天开启双图 | 同时刻、同视角遮罩一致 |
| 全国→省→市→县，跨省平移 | 边界、名称和搜索可达，缺失数必须为 0 或用户明确核准的层级例外 |
| 海岛／飞地／直辖市／省直管县 | 几何与上下级关系正确，不依赖固定三层树 |
| 主图与南海附图同地同刻 | 昼夜状态一致 |
| 北京、上海、乌鲁木齐、拉萨、漠河、三亚、香港、澳门、台北 | 代表点与公开天文参考值交叉核对；明确参考模型后日出日落差值目标不超过 2 分钟 |
| 夏冬代表日期、夜间、晨昏、正午 | 无硬编码左右扫屏，三态判定与遮罩一致 |
| 手机竖屏、横屏、桌面缩放 | 控件可操作，日期与时间不被截断，无必须依赖 hover 的功能 |

## 11. 已闭合决策与实现调整

用户已允许公开转载／转换的官方数据；最终找到免账号、免Key的官方公开地图响应，采用其直接快照。用户已明确批准开始编码。地图取得日2026-10-02，官方页面标示数据更新时间为2025年9月局部更新，不将取得日冒称行政区更新时间。

昼夜遮罩改用WebGL片元着色器：对每个地理位置计算与同一太阳向量的夹角，不需要随缩放采样等值多边形。遮罩与详情模型一致，阈值附近仅做窄带抗锯齿。原始边界不简化，图形引擎按缩放裁切。

地图标注点与天文代表点分开；23个面外官方标注点的详情改用根据官方边界计算的内部代表点，并明确标注。特殊管理层级注明，辅助区域保留几何但不混入省市县列表。
