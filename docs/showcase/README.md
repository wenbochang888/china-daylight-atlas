这些图片从当前应用实际页面捕获，场景时间固定用于展示，不代表截图取得时的实时北京时间。原始尺寸与检查结果见 [capture.json](capture.json)。

截图使用 Chromium。手机场景启用触控与移动设备模拟，页面滚动到底部后捕获全页，使固定时间轴和南海附图完整呈现；不代表真实手机验证。检查确认各地图有 34 个省级名称、六个南海注记，无横向溢出或页面脚本错误，并人工查看最终图片。

分享封面为 2:1 PNG，约 234 KB。需要设置时，在仓库 **Settings → General → Social preview → Edit → Upload an image** 上传 `social-preview.png`。提交该文件本身不会自动设置 GitHub 分享封面。

演示视频由维护者录制；根目录 README 的“演示视频”章节已留空，可直接加入视频链接。
