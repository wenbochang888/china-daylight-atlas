# 固定全国总览、大时间与彩色昼夜验证

本记录对应2026-10-03批准的固定地图计划。原观测台、日期控制和音频验证记录保留，不作为本轮通过的依据。

## 实际实现

- 全国主图保持完整比例，以展示集合范围和桌面24px／手机16px边距拟合。桌面外边距与栏间距为12px，右栏保持320px。地图导航手势关闭，删除缩放与全境按钮。
- 页面只允许选择34个省级地区。行政面与名称均可点击；港澳面有3px点击容差，海岸像素舍入时也允许邻近面回退。选中只高亮并显示代表点详情，不移动相机或改变播放；手机直接打开原生详情面板，关闭恢复入口焦点。
- 主图只分离整块南海部件和对应境界线，不裁切多边形、不修改原始或派生地图文件。海南主体及近岸岛屿保留；主图范围为73.498962°—135.087387°E、18.162997°—53.558498°N。全国播放继续使用完整原始几何，倍率固定为1。
- 原时钟保持，新增共享分钟大时间，显示00:00—24:00。通过地图投影定位，不增加定时器或动画循环。主附图共用青绿陆地、浅蓝海面、深蓝夜色和金色强调；夜色透明度0.78，太阳阈值不变。
- 南海附图使用独立地图和太阳向量，桌面144×188px、手机112×154px。宽度不足600px的地图将附图放在单独底部区域，避免覆盖海南、台湾和东南沿海。六个名称均保留。

视觉检查生成于2026-10-03北京时间21:23，覆盖360×800、390×844、768×1024、844×390、1280×720、1360×900、1440×900、1920×1080。场景包括单图、双图、详情、节气／日期面板、全白天、全黑夜、昼夜交界、两日季节对比、加载与错误状态；另有WebKit夜间及日历截图。

最终浏览器回归覆盖桌面Chromium、手机尺寸WebKit和手机尺寸Chromium。桌面24项通过，两个手机项目各20项通过、4项跳过。跳过的是仅在桌面专项运行的特殊省级名称命中、快速节气竞态、WebGL初始化故障和地图容器排列断点；相关用例在桌面均通过。最终使用独立输出目录，避免并行测试覆盖追踪文件；此前失败运行不计为通过。

人工检查了桌面单图与双图、窄桌面双图、手机单图与双图、白天、夜间及季节对比。大时间位于中国轮廓背部上方，不拦截点击；窄图附图不再覆盖海南或港澳台。调整澳门标签与海南北端的距离，并将黄岩岛名称与中沙群岛错开。自动检查主附图的六个南海名称，加载／错误场景除外。

浏览器回归重点包括：全国相机在滚轮、拖动、双击、键盘和模拟触摸缩放后不变；河南与海南点击后不取下级分片；台湾、直辖市、港澳面及标签专项命中；双图相机一致；时间轴点击／拖动／方向键／Home／End与全部时钟一致；图形故障及资源重试；详情关闭与焦点恢复。

验证过程中处理了手机WebKit不支持鼠标滚轮API的测试限制：该项目使用DOM滚轮事件，其他项目使用实际鼠标滚轮。触摸检查为浏览器事件模拟。音乐回归同时遇到工作区新的音频时间轴改动，最终以当前文件重新运行；本轮地图实现未调整音乐产品规则。

音频日终检查删除了重复的5毫秒严格断言，继续由统一`musicAt`检查位置误差小于50毫秒：实测6—11毫秒误差小于产品20毫秒定位阈值。后台暂停检查等待媒体`pause`事件后再记录位置，避免把尚未完成暂停的进度作为基准。
