# 时间居中、节气标签与 H5 标注验证

日期：2026-10-05。本记录仅描述本轮实际执行结果。

后续节气显示已改为日期后括号，以下独立标签布局作为历史记录保留；最新结果见[日期同行节气验证](validation-inline-terms.md)。

## 实际变更

- 时间信息组在每张地图水平居中，底边随中国轮廓最北端定位，手机／窄图间距12px、宽图16px。日期、北京时间和时间保持三行；普通、全屏及双图采用同一规则。
- 信息组下方预留24px节气位置及8px间隔，普通日期没有标签；固定预留避免换日期时移动地图。两图使用统一最大顶部需要；按钮水平冲突时信息组排在按钮下方。全屏安全区只在拟合时计入，不再重复加卡片外边距。
- 标签按所选北京时间日期匹配其年份的24节气，上一年、手动日期、节气入口和双图各自日期均适用。到24:00保留所选日期节气。计算失败清除标签并显示原有可重试错误。
- 省名先尝试文字位于最大可见主体内。狭长省份或桌面完整省名无法全部容纳时，允许边缘跨省界，中心仍在所属省且文字框互不重叠；极小区域或无空位的省份外置并引线指向锚点。原始行政几何、官方标注点、天文代表点及全称不变。
- 钓鱼岛最后参与避让，手机／窄地图显示“钓鱼岛”，宽地图保留完整组名，优先排在东侧海面。使用随程序内置的岛屿注记，避免布局初始化时依赖尚未就绪的 worker 分片。
- 几何候选点缓存复用，位置计算仅随布局与相机变化执行；不新增播放帧计算或外部依赖。保留本轮开始前及期间的 iOS 相关工作区改动。

## 执行与结果

| 检查 | 实际结果 |
| --- | --- |
| `npm run typecheck` | 通过 |
| `npm run test:unit` | 11个文件、72项通过，含新增节气日期、孔洞／凹形／多部件、内部／外置及确定性排布检查 |
| `npm run build` | 通过；构建仍提示部分产物超过配置的体积提醒阈值 |
| 三浏览器相关E2E | 32项通过、4项按浏览器能力跳过，见下面说明 |
| 最终布局三浏览器定向复查 | 时间位置、节气、省内中心与避让12项全部通过 |
| 最终产物 `/atlas/` 检查 | 8种视口通过；结果保存在本轮 `static-production.json` |

浏览器命令：

```sh
npm run test:e2e -- tests/e2e/fullscreen-clock.spec.ts tests/e2e/map-labels-terms.spec.ts tests/e2e/fullscreen.spec.ts --output=/tmp/atlas-labels-final-e2e
npm run test:e2e -- tests/e2e/fullscreen.spec.ts --project=desktop-chromium --grep '双图全屏均分空间' --output=/tmp/atlas-labels-rotation-recheck
npm run test:e2e -- tests/e2e/fullscreen-clock.spec.ts tests/e2e/map-labels-terms.spec.ts --output=/tmp/atlas-labels-final-layout
node scripts/static-check.mjs --map-labels-terms --audio-timeline
```

首轮三浏览器回归为31项通过、4项跳过、1项查询异常。异常发生在桌面双图旋转后，测试在MapLibre文字更新期间读取渲染要素。测试改为等待地图加载完成后读取，同一场景复查通过；以上32项为去重后的通过场景数，未将首轮失败算作通过。手机项目跳过的4项为桌面专用附图尺寸切换和原生全屏测试。

覆盖桌面Chromium、手机尺寸Chromium及WebKit；省名排布检查包括360、390、599、600、844横屏、1440桌面。原生及备用全屏、双图旋转、34个标注、简称点击及完整详情、画布／音频复用、暂停及音乐继续、日终重播、迟到全屏请求均有相关回归。

新增E2E同时检查标注文字框无重叠，并以实际省级面查询验证省内标注的中心归属；手动夏至、上一年冬至、两图独立标签、普通日期消失及24:00归属通过。换节气标签前后相机一致；亮暗主题下布局可读。几何单元测试另验证孔洞、凹陷、多部件最大主体、输入不被修改及候选缓存。

生产检查覆盖1440×900、768×1024、844×390、360×800、390×844、599×900、600×900、601×900，使用纽约设备时区。日期仍按北京时间解释；各信息组居中且未与操作按钮重叠，无横向溢出或页面错误，无第三方运行时请求。固定MP3从`/atlas/assets/`加载，类型`audio/mpeg`、曲长265秒、原生循环、速率1，双图共用音频且暂停后声音停止。
